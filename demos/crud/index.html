CRUD Backend — Demo (static preview)

This page documents the REST endpoints implemented in the backend project and provides a static preview. Full deployment requires providing a MongoDB URI as an environment variable and running the server.

Deployment notes

  • Set environment variable MONGODB_URI in the host.
  • Run npm install && npm start (or npm run start) in the project root.
  • Do not expose credentials publicly. Use the hosting platform's secrets store.
